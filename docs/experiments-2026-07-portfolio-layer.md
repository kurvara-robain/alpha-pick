# 组合层实现实验记录：三个被否决的假设

**日期**：2026-07-25
**信号**：ML 合成信号（HistGradientBoosting，15 个实测有效因子截面秩合成，样本外 IC20=0.082 / ICIR=0.95）
**实验区间**：2025-11 ~ 2026-07（33 个周度调仓期，8.2 个月，严格样本外）
**成本假设**：双边 0.1% × 换手（佣金+印花+滑点近似）
**基准**：沪深300

> 本文固化组合层（信号→持仓）三次对照实验的结论，避免后续重复试错。
> 所有原始数据在 `public/data/ml-backtest*.json`，可用环境变量复现（见文末）。

## 结论先行

**该信号的 alpha 高度集中在生效后第一周，任何"延迟兑现新鲜排名"的实现方式都会摧毁超额收益。**
当前采用配置 = 正确实现：**top100 等权、每周全量调仓、无缓冲带、无行业约束**。

| # | 方案 | 年化超额 | 最大回撤 | 夏普 | 周换手 | 判定 |
|---|---|---|---|---|---|---|
| 0 | 基线 top30 周度全调 | +7.5% | -19.0% | 0.29 | 78.7% | — |
| 1 | **top100 周度全调（现用）** | **+8.3%** | **-18.5%** | **0.33** | 73.3% | ✅ 最优 |

**信号真实有效，损耗全部发生在实现层。**

## 假设一：换手缓冲带（否决）

- **假设**：排名在 top 边缘 churn 的股票反复买卖是成本浪费；跌出前 60 名才卖出可省成本。
- **结果**：周换手仅降 10pp（省 ~1%/年），gross alpha 掉 ~9%/年。
- **机理**：跌出前 30 的股票是**真的开始跑输**——排名下滑本身就是信号失效，缓冲带等于强制持有正在失效的持仓。适用对象是慢信号（价值/质量类），不适用于以反转和量能为骨架的快信号。

## 假设二：行业中性（否决）

- **假设**：单行业持仓上限可分散风险、提升稳健性。
- **结果**：超额从 +7.5% → +4.7%。
- **机理**：样本期内 alpha 高度集中于半导体/电子行情，强制分散 = 主动剔除最强持仓。行业约束是风控工具而非收益工具；在 8 个月短样本内其 alpha 代价清晰可见。**10 年回测就位后需复核**（行业轮动的长期代价/收益可能不同）。

## 假设三：梯队错周调仓（否决）

- **假设**：标签为 20 日前瞻收益，持仓应匹配 20 日 horizon；资金分 4 梯队错周调仓，每周仅 1/4 仓位换手，理论省 3/4 成本。
- **结果**：换手 78.7% → 24.3%（省 ~11%/年，符合设计），但 gross alpha 塌 ~26%/年，超额转负。
- **机理**：20 日标签是训练目标，不代表 alpha 在 20 日内匀速分布——实测 alpha 集中在第一周，持仓第 2-4 周为负贡献。**标签 horizon ≠ 最优持有期**，这是本次实验最重要的认知。

## 唯一正向发现：分散化

top30 → top100：超额 +7.5% → +8.3%，回撤、夏普、换手全面改善。
单票特异性风险是该组合的主要噪声来源，分散化是零成本改进。

## 遗留问题（10 年数据就位后验证）

1. 8.2 个月单 regime 样本的稳健性——10 年回测覆盖 2018 熊市 / 2019-21 结构牛 / 2022-24 调整 / 2024-09 脉冲后重新验证全部结论。
2. 行业中性在长期多 regime 下是否仍为净负贡献。
3. 幸存者偏差：当前回测股票池为现存上市股票，缺退市股，长期超额偏乐观，需知悉。
4. 下一步候选方向（不在调仓结构）：信号新鲜度加权（当周新信号权重上调）、风险覆盖层（波动率目标/回撤刹车）、beta 中性化对冲回撤。

## 复现方式

```bash
cd /path/to/alpha-pick
# 基线 top100（现用正式版）
python3 scripts/ml-backtest.py
# 缓冲带：BT_BUFFER=60 BT_TOPN=30 BT_RETRAIN=4 BT_LASTN=260 BT_OUT="-buffer" python3 scripts/ml-backtest.py
# 行业中性：BT_INDCAP=3 BT_BUFFER=30 BT_RETRAIN=4 BT_LASTN=260 BT_OUT="-indonly" python3 scripts/ml-backtest.py
# 梯队错周：BT_TRANCHES=4 BT_RETRAIN=4 BT_LASTN=260 BT_OUT="-tranche4" python3 scripts/ml-backtest.py
```

环境变量：`BT_TOPN` 持股数 / `BT_BUFFER` 缓冲带名次 / `BT_INDCAP` 行业上限 / `BT_TRANCHES` 梯队数 / `BT_RETRAIN` 重训间隔（截面）/ `BT_LASTN` 只用最近 N 天日历 / `BT_OUT` 输出文件后缀。
